# iremkrc.github.io

Personal academic website of **İrem Karaca** — built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme.

## About

İrem is a Master's student in Machine Learning at the [University of Tübingen](https://uni-tuebingen.de/) and a research-oriented master's scholar at [ELIZA](https://eliza.school/). She works as a research assistant at the [ELLIS Institute Tübingen](https://institute-tue.ellis.eu/) on the AIS project, an open-source AI tutoring platform, in the team led by Wieland Brendel.

Her academic interests focus on **AI Safety & Alignment** and **LLMs**.

## Tech Stack

- **Theme:** [al-folio](https://github.com/alshedivat/al-folio) — Jekyll theme for academics
- **Hosted on:** GitHub Pages
- **Language:** Ruby / Jekyll

## Local Development

```bash
bundle install
bundle exec jekyll serve
```

Or with the local config:

```bash
bundle exec jekyll serve --config _config.yml,_config_local.yml
```
